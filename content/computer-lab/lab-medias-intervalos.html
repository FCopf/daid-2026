Médias que variam e intervalos que cobrem

Prática em R 03

Prof. Fabio Cop (fcferreira@unifesp.br)

Instituto do Mar - Unifesp

Data de Publicação

13 de agosto de 2026

1 Objetivo desta prática

A leitura desta semana mostrou cem intervalos de confiança e contou quantos continham o valor real. Você viu que o procedimento acerta cerca de 95% das vezes.

Um intervalo, porém, tem duas propriedades, e a leitura só mediu uma delas. Além de acertar com certa frequência, ele tem uma largura, e é a largura que diz se o estudo estabeleceu alguma coisa. Hoje você vai medir as duas ao mesmo tempo, em dois tamanhos de amostra, e descobrir qual das duas muda.

O objetivo em R é construir um experimento de verificação, gerando muitas coletas, calculando um intervalo para cada uma e resumindo o desempenho do procedimento.

NotaComo a hora será usada
  • 5 min abrir o RStudio, criar o script e ler a proposta;
  • 40 a 45 min percorrer as seções guiadas e fazer o bloco Sua vez;
  • 10 a 15 min escrever as respostas, rodar o script do início ao fim e enviar.

2 Preparação

Crie um script pr-medias-intervalos.R com o cabeçalho de identificação e comece por:

library(tidyverse)
theme_set(theme_bw(base_size = 12))

Com dados reais nunca sabemos o valor que estamos estimando. Aqui vamos fazer o contrário e inventar um costão cujo comprimento médio dos mexilhões é exatamente 5 cm. Sabendo a resposta de antemão, podemos verificar se o método acerta, e com que frequência.

Os parâmetros ficam no início do script, para serem fáceis de mudar depois:

media_real <- 5     # comprimento médio no costão, em cm
desvio_real <- 1    # desvio-padrão entre mexilhões, em cm
n <- 20             # mexilhões por amostra

3 Uma equipe vai ao costão

Coletar 20 mexilhões e medi-los é uma linha de código:

amostra <- rnorm(n, mean = media_real, sd = desvio_real)

mean(amostra)
[1] 4.89941
sd(amostra)
[1] 0.837998

A média observada não é exatamente 5, e não deveria ser, porque são 20 mexilhões sorteados, não o costão inteiro.

A leitura mostrou que o espalhamento dessas médias, entre coletas repetidas, pode ser estimado a partir de uma única amostra, pela fórmula do erro padrão:

\[s_{\bar{x}} = \frac{s}{\sqrt{n}}\]

DicaComplete

Traduza a fórmula para o R. sd(amostra) é o \(s\), e falta o denominador.

erro_padrao <- sd(amostra) / sqrt(____)
erro_padrao
[1] 0.187382

Com a média e o erro padrão, construímos o intervalo de confiança de 95%. A função qt() fornece o multiplicador da distribuição t, que depende dos graus de liberdade (\(n - 1\)):

multiplicador <- qt(0.975, df = n - 1)

inferior <- mean(amostra) - multiplicador * erro_padrao
superior <- mean(amostra) + multiplicador * erro_padrao

c(inferior, superior)
[1] 4.507215 5.291605

Este é o intervalo desta coleta. Ele contém 5 cm, ou não contém, e com uma amostra só você nunca saberia qual dos dois casos ocorreu. Para julgar o procedimento, é preciso repeti-lo.

4 Duas propriedades do procedimento

Vamos construir 200 coletas, calcular um intervalo para cada uma e resumir o conjunto por duas medidas, a proporção que contém o valor real e a largura média dos intervalos.

coletas <- tibble(
  id = rep(1:200, each = n),
  comprimento = rnorm(200 * n, mean = media_real, sd = desvio_real)
)

intervalos <- coletas |>
  group_by(id) |>
  summarise(
    media = mean(comprimento),
    erro = qt(0.975, df = n - 1) * sd(comprimento) / sqrt(n),
    .groups = "drop"
  ) |>
  mutate(
    inferior = media - erro,
    superior = media + erro,
    cobre = inferior <= media_real & superior >= media_real,
    largura = superior - inferior
  )

resumo_20 <- intervalos |>
  summarise(
    mexilhoes_por_amostra = n,
    cobertura = mean(cobre),
    largura_media = mean(largura)
  )

resumo_20
# A tibble: 1 × 3
  mexilhoes_por_amostra cobertura largura_media
                  <dbl>     <dbl>         <dbl>
1                    20     0.965         0.917

Duas observações sobre o código. A coluna cobre guarda TRUE ou FALSE para cada intervalo, e a média de um vetor lógico é a proporção de TRUE. A coluna largura é simplesmente a distância entre os dois limites.

DicaObserve

A cobertura obtida não será exatamente 95%: são 200 coletas sorteadas, e essa proporção também varia de execução para execução. Rode o bloco mais uma vez para ver o número oscilar.

5 Sua vez

Você tem o desempenho do procedimento para amostras de 20 mexilhões. Falta saber o que acontece quando a amostra muda de tamanho.

DicaEscolha

Escolha um segundo tamanho de amostra, diferente de 20, entre 5, 10, 50 ou 100. Registre a escolha no script.

DicaPreveja antes de rodar

O resumo tem duas colunas. Antes de executar qualquer coisa, escreva no script, como comentário, o que você espera que aconteça com cada uma delas quando o tamanho da amostra mudar:

  • a cobertura vai subir, descer ou ficar parecida?
  • a largura média vai subir, descer ou ficar parecida?

As duas respostas não são iguais. Registre as duas antes de olhar.

Para produzir o segundo resultado, duplique no seu script o bloco dos 200 intervalos, trocando o valor de n no início e guardando o resumo com outro nome:

n <- ____            # o tamanho que você escolheu

# ... cole aqui o bloco dos 200 intervalos ...

resumo_meu <- intervalos |>
  summarise(
    mexilhoes_por_amostra = n,
    cobertura = mean(cobre),
    largura_media = mean(largura)
  )

Por fim, junte os dois resumos em uma tabela só, para poder comparar as linhas:

bind_rows(resumo_20, resumo_meu)
AvisoCuidado com a ordem

Todo o bloco usa o objeto n. Se você mudar n e não reexecutar as linhas que vêm depois, a tabela sairá com números misturados de dois tamanhos diferentes.

Por isso o script precisa rodar do início ao fim em sessão nova antes de ser enviado, porque é assim que você garante que cada resumo corresponde ao n que está escrito ao lado dele.

6 Entrega

Salve o script pr-medias-intervalos.R com o cabeçalho preenchido. Antes de enviar, reinicie o R (Session → Restart R) e execute o script inteiro uma vez. As respostas escritas vão no próprio script, como comentários iniciados por #.

  4. em comentários, 3 a 4 frases respondendo, com os seus dois pares de números: dois estudos informam intervalos de 95% para a mesma população, um com amostra grande e outro com amostra pequena. Os dois acertam com a mesma frequência? Então o que exatamente o estudo maior comprou com o esforço extra de coleta?
  5. em comentários, uma conta: partindo do n = 20, quantos mexilhões seriam necessários para obter um intervalo com metade da largura obtida ali? Use as suas duas larguras para conferir se a sua resposta é coerente com o que você observou.
