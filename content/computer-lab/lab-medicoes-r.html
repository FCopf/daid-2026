1 Cinco poças, cinco temperaturas

Você mediu a temperatura da água em cinco poças de maré de um costão rochoso e anotou:

25,4; 25,9; 24,8; 26,3; 25,1 °C

Cinco números diferentes para a mesma coisa. Nesta prática vamos colocar essas medidas no R, descrever o que elas têm em comum, ver como elas se distribuem e, no fim, pedir ao computador que gere novas medidas como se tivéssemos voltado ao costão.

Abra o RStudio, crie um script novo e comece por aqui:

library(tidyverse)
theme_set(theme_bw(base_size = 12))

A primeira linha carrega o conjunto de pacotes que usaremos o semestre inteiro. A segunda define a aparência dos gráficos, para não termos de repetir isso depois.

DicaDica

Se aparecer there is no package called 'tidyverse', instale-o uma única vez com install.packages("tidyverse") e execute o library() novamente.

2 Vamos guardar as medidas

No R, guardamos valores dentro de objetos. A seta <- faz essa atribuição, e c() junta vários números em um vetor.

temperatura <- c(25.4, 25.9, 24.8, 26.3, 25.1)
temperatura
[1] 25.4 25.9 24.8 26.3 25.1

Note que no R o separador decimal é o ponto, não a vírgula.

Com o vetor criado, podemos perguntar coisas a ele:

length(temperatura)
[1] 5
mean(temperatura)
[1] 25.5
sd(temperatura)
[1] 0.6041523

length() conta quantos valores existem, mean() calcula a média e sd() mede o quanto os valores se espalham em torno dela.

DicaObserve

A média fica perto de 25,5 °C, mas nenhuma poça mediu exatamente isso. A média é um resumo do conjunto, não uma das medidas.

3 Uma poça tem mais de uma característica

Na prática você não anota só a temperatura. Anota também a profundidade, o sombreamento, o identificador da poça. Para isso precisamos de uma tabela, onde cada linha é uma poça e cada coluna é uma característica medida nela.

pocas <- tibble(
  poca = 1:5,
  temperatura = c(25.4, 25.9, 24.8, 26.3, 25.1),
  profundidade = c(12, 8, 20, 6, 15),
  sombreamento = c("baixo", "baixo", "alto", "baixo", "médio")
)

pocas
# A tibble: 5 × 4
   poca temperatura profundidade sombreamento
  <int>       <dbl>        <dbl> <chr>       
1     1        25.4           12 baixo       
2     2        25.9            8 baixo       
3     3        24.8           20 alto        
4     4        26.3            6 baixo       
5     5        25.1           15 médio

Cinco linhas, cinco poças. A saída mostra também o tipo de cada coluna: <dbl> para números com casas decimais, <int> para inteiros, <chr> para texto.

Para ver a estrutura de uma tabela rapidamente, use glimpse():

glimpse(pocas)
Rows: 5
Columns: 4
$ poca         <int> 1, 2, 3, 4, 5
$ temperatura  <dbl> 25.4, 25.9, 24.8, 26.3, 25.1
$ profundidade <dbl> 12, 8, 20, 6, 15
$ sombreamento <chr> "baixo", "baixo", "alto", "baixo", "médio"

4 Como escolher só uma parte da tabela?

Duas operações resolvem quase tudo no começo: filter() escolhe linhas e select() escolhe colunas.

pocas |> filter(profundidade > 10)
# A tibble: 3 × 4
   poca temperatura profundidade sombreamento
  <int>       <dbl>        <dbl> <chr>       
1     1        25.4           12 baixo       
2     3        24.8           20 alto        
3     5        25.1           15 médio

O símbolo |> é o pipe: ele leva o valor da esquerda para o primeiro argumento da função à direita. Leia como “tome pocas, e então filtre”.

pocas |> select(poca, temperatura)
# A tibble: 5 × 2
   poca temperatura
  <int>       <dbl>
1     1        25.4
2     2        25.9
3     3        24.8
4     4        26.3
5     5        25.1

Para criar uma coluna nova, use mutate():

pocas |> mutate(diferenca = temperatura - mean(temperatura))
# A tibble: 5 × 5
   poca temperatura profundidade sombreamento diferenca
  <int>       <dbl>        <dbl> <chr>            <dbl>
1     1        25.4           12 baixo           -0.100
2     2        25.9            8 baixo            0.400
3     3        24.8           20 alto            -0.700
4     4        26.3            6 baixo            0.800
5     5        25.1           15 médio           -0.400

A nova coluna mostra quanto cada poça se afasta da média: valores negativos são poças mais frias que a média, positivos são mais quentes.

DicaModifique

Troque profundidade > 10 por sombreamento == "baixo" e execute novamente. Repare que comparação de texto usa == e aspas.

5 As poças sombreadas são mais frias?

Cinco poças são poucas, mas o procedimento é o mesmo com quinhentas. Para resumir por grupo, combine group_by() com summarise():

pocas |>
  group_by(sombreamento) |>
  summarise(
    n = n(),
    media = mean(temperatura),
    desvio = sd(temperatura)
  )
# A tibble: 3 × 4
  sombreamento     n media desvio
  <chr>        <int> <dbl>  <dbl>
1 alto             1  24.8 NA    
2 baixo            3  25.9  0.451
3 médio            1  25.1 NA

O desvio aparece como NA onde há uma única poça: não é possível medir espalhamento com um único valor.

6 O que o gráfico mostra?

Números resumem; gráficos revelam. Todo gráfico do ggplot2 tem três partes: os dados, o mapeamento entre variáveis e eixos (aes) e a forma de desenhar (geom_).

ggplot(pocas, aes(x = profundidade, y = temperatura, colour = sombreamento)) +
  geom_point(size = 4) +
  labs(x = "Profundidade (cm)", y = "Temperatura (°C)", colour = "Sombreamento")
DicaObserve

Com cinco pontos, qualquer padrão aparente pode ser coincidência. A pergunta certa a fazer diante deste gráfico é: quantas poças eu precisaria medir para confiar no que estou vendo?

7 E se o computador gerasse as medidas?

Aqui entra a ferramenta que usaremos o semestre inteiro. A função rnorm() sorteia valores em torno de um centro, com um espalhamento que você define:

rnorm(5, mean = 25.5, sd = 0.6)
[1] 25.03616 25.57747 25.05360 24.94085 24.70079

Os três argumentos são explícitos: quantos valores gerar, qual a média e qual o desvio-padrão.

Execute essa linha algumas vezes seguidas. Cada execução produz cinco números diferentes, e é essa a ideia de “voltar ao costão e medir outras cinco poças”. Os números desta página também mudam a cada vez que o material é gerado.

DicaDica

Quando é preciso que um sorteio se repita exatamente igual (para conferir um resultado com um colega, por exemplo), o R oferece a função set.seed(), que fixa o ponto de partida do sorteio:

set.seed(1)
rnorm(5, mean = 25.5, sd = 0.6)

Não vamos usá-la nesta unidade curricular. A variação entre execuções é justamente o que queremos observar.

Agora vamos gerar trinta poças e olhar a distribuição delas:

simuladas <- tibble(
  poca = 1:30,
  temperatura = rnorm(30, mean = 25.5, sd = 0.6)
)

ggplot(simuladas, aes(x = temperatura)) +
  geom_histogram(bins = 12, fill = "#0072B2", colour = "white") +
  labs(x = "Temperatura (°C)", y = "Número de poças")
simuladas |>
  summarise(
    media = mean(temperatura),
    desvio = sd(temperatura)
  )
# A tibble: 1 × 2
  media desvio
  <dbl>  <dbl>
1  25.5  0.572

A média e o desvio calculados a partir das trinta poças ficam perto dos valores que pedimos, mas não idênticos. Isso não é erro: é o que acontece quando se mede uma parte em vez do todo.

DicaModifique

Execute o bloco acima trocando sd = 0.6 por sd = 2. Depois volte para 0.6 e troque 30 por 300.

Para cada mudança, observe:

  • o histograma ficou mais largo ou mais estreito?
  • a média calculada ficou mais perto ou mais longe de 25,5?

8 Duas amostras do mesmo costão

Uma última pergunta, e ela vale guardar: se o costão é o mesmo, duas amostras produzem a mesma média?

amostra_a <- rnorm(30, mean = 25.5, sd = 0.6)
amostra_b <- rnorm(30, mean = 25.5, sd = 0.6)

media_a <- mean(amostra_a)
media_b <- mean(amostra_b)

c(media_a, media_b)
[1] 25.49417 25.35500

Mesmo processo gerador, médias diferentes: nesta execução elas ficaram separadas por 0,14 °C. Nenhuma das duas é a média “verdadeira” de 25,5 e, com dados reais, nunca saberíamos qual está mais perto.

# Duas amostras do mesmo costão

Uma última pergunta, e ela vale guardar: se o costão é o mesmo, duas amostras produzem a mesma
média?

```{r}
amostra_a <- rnorm(30, mean = 25.5, sd = 0.6)
amostra_b <- rnorm(30, mean = 25.5, sd = 0.6)

media_a <- mean(amostra_a)
media_b <- mean(amostra_b)

c(media_a, media_b)
```

```{r}
#| echo: false
dif_txt <- formatC(abs(media_a - media_b), format = "f", digits = 2, decimal.mark = ",")
```

Mesmo processo gerador, médias diferentes: nesta execução elas ficaram separadas por `r dif_txt` °C. Nenhuma das duas é a média "verdadeira" de 25,5 e, com
dados reais, nunca saberíamos qual está mais perto.
