Quantas vezes a dieta foi sorteada?

Prática em R 04

Prof. Fabio Cop (fcferreira@unifesp.br)

Instituto do Mar - Unifesp

Data de Publicação

11 de agosto de 2026

1 Objetivo desta prática

A leitura desta semana mostrou que peixes do mesmo tanque não são réplicas e que a análise deve ser feita no nível da unidade experimental. Você viu a estrutura do problema.

O que a leitura não mediu é o preço de errar esse nível. Hoje você vai medir duas coisas: com que frequência a análise errada anuncia um efeito que não existe, e de que depende, afinal, o erro padrão da análise correta.

O objetivo em R é escrever uma função e repetir um experimento inteiro centenas de vezes.

NotaComo a hora será usada
  • 5 min abrir o RStudio, criar o script e ler a proposta;
  • 40 a 45 min percorrer as seções guiadas e fazer o bloco Sua vez;
  • 10 a 15 min escrever as respostas, rodar o script do início ao fim e enviar.

2 Preparação

Crie um script pr-replicacao.R com o cabeçalho de identificação e comece por:

library(tidyverse)
theme_set(theme_bw(base_size = 12))

Duas dietas para juvenis de robalo. Oito tanques: quatro recebem a dieta comum, quatro a enriquecida. Quinze peixes em cada tanque. Cento e vinte medidas de comprimento, e a dieta sorteada oito vezes.

Vamos construir esse experimento no computador, em dois passos, para saber exatamente qual é a verdade. Primeiro cada tanque recebe o seu próprio desvio:

efeito_dieta <- 0             # nenhuma diferença entre as dietas
variacao_entre_tanques <- 0.8
variacao_entre_peixes <- 0.5

tanques <- tibble(
  tanque = 1:8,
  dieta = rep(c("comum", "enriquecida"), each = 4),
  media_tanque = 10 + if_else(dieta == "enriquecida", efeito_dieta, 0) +
    rnorm(8, mean = 0, sd = variacao_entre_tanques)
)

Repare que efeito_dieta vale zero: as duas dietas são idênticas. Toda diferença entre tanques vem do rnorm() da última linha, ou seja, do acaso de cada tanque.

Agora os peixes, sorteados em torno da média do seu tanque:

peixes <- tanques |>
  slice(rep(1:8, each = 15)) |>
  mutate(comprimento = rnorm(n(), mean = media_tanque, sd = variacao_entre_peixes))

ggplot(peixes, aes(x = factor(tanque), y = comprimento, colour = dieta)) +

  stat_summary(fun = mean, geom = "crossbar", width = 0.6, linewidth = 0.4, colour = "black") +
  labs(x = "Tanque", y = "Comprimento (cm)", colour = "Dieta")

slice(rep(1:8, each = 15)) repete cada linha de tanque 15 vezes, criando 15 peixes por tanque, e n() devolve o número de linhas da tabela naquele momento — aqui, 120.

A tentação é resumir cada dieta com todos os seus peixes. A alternativa é primeiro reduzir cada tanque a um valor, porque é o tanque que recebeu a dieta.

4 Com que frequência cada análise dá um alarme falso?

Um experimento só não decide nada: cada execução sorteia tanques diferentes. A pergunta certa é sobre o comportamento a longo prazo de cada análise.

Como a dieta não faz nada, sempre que os dois intervalos de uma análise não se sobrepõem nós anunciaríamos uma diferença que não existe. Vamos medir com que frequência isso acontece.

limites <- function(valores) {
  ep <- sd(valores) / sqrt(length(valores))
  mean(valores) + c(-1, 1) * qt(0.975, length(valores) - 1) * ep
}

separados <- function(a, b) limites(a)[1] > limites(b)[2] || limites(b)[1] > limites(a)[2]

function() cria um comando novo: os nomes entre parênteses são os valores que ele recebe e a última linha é o que ele devolve. limites() guarda a conta da Prática 03; separados() responde TRUE quando os dois intervalos não se tocam.

alarmes <- replicate(300, {
  tq <- tibble(
    tanque = 1:8,
    dieta = rep(c("comum", "enriquecida"), each = 4),
    media_tanque = 10 + rnorm(8, mean = 0, sd = variacao_entre_tanques)
  )

  px <- tq |>
    slice(rep(1:8, each = 15)) |>
    mutate(comprimento = rnorm(n(), mean = media_tanque, sd = variacao_entre_peixes))

  mt <- px |>
    group_by(tanque, dieta) |>
    summarise(media = mean(comprimento), .groups = "drop")

  c(
    peixes  = separados(px$comprimento[px$dieta == "comum"],
                        px$comprimento[px$dieta == "enriquecida"]),
    tanques = separados(mt$media[mt$dieta == "comum"],
                        mt$media[mt$dieta == "enriquecida"])
  )
})

5 De que depende o erro padrão de cada análise?

Se medir mais peixes por tanque resolvesse o problema, bastaria trabalhar mais. Vamos verificar, repetindo o experimento com três quantidades de peixes por tanque e olhando os dois erros padrão. Como cada execução varia, cada valor é a média de 100 experimentos.

ep_medio <- function(m) {
  vals <- replicate(100, {
    px <- tibble(
      tanque = 1:8,
      media_tanque = 10 + rnorm(8, mean = 0, sd = variacao_entre_tanques)
    ) |>
      slice(rep(1:8, each = m)) |>
      mutate(comprimento = rnorm(n(), mean = media_tanque, sd = variacao_entre_peixes))

    mt <- px |> group_by(tanque) |> summarise(media = mean(comprimento), .groups = "drop")

    c(sd(px$comprimento) / sqrt(nrow(px)), sd(mt$media) / sqrt(8))
  })
  c(peixes_por_tanque = m, ep_peixes = mean(vals[1, ]), ep_tanques = mean(vals[2, ]))
}

bind_rows(ep_medio(15), ep_medio(50), ep_medio(150))
# A tibble: 3 × 3
  peixes_por_tanque ep_peixes ep_tanques
              <dbl>     <dbl>      <dbl>
1                15    0.0815      0.279
2                50    0.0440      0.271
3               150    0.0253      0.269
DicaInterprete

Leia a tabela coluna a coluna. ep_peixes cai quando se mede mais peixes por tanque. ep_tanques praticamente não se move.

Ou seja: ep_tanques não depende de quantos peixes foram medidos. De que ele depende, então? O bloco seguinte pede que você descubra.
