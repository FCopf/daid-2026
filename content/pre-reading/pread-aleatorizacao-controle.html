1 Cento e vinte peixes para distribuir

Uma pesquisadora vai comparar duas dietas para juvenis de robalo. Dependendo do orçamento disponível, do tempo estimado de processamento e do espaço físico, ela pode escolher entre algumas opções:

  • Dois tanques de 60 peixes;
  • Quatro tanques de 30 peixes;
  • Oito tanques de 15 peixes;
  • Vinte tanques de 6 peixes.

Cada uma dessas opções tem uma capacidade diferente de responder à pergunta. Vamos explorar as consequências de cada escolha, exercício que sempre deve ser feito antes do início do experimento.

2 Primeira decisão: quantas unidades experimentais?

Peixes do mesmo tanque compartilham as condições daquele tanque, e a dieta é atribuída ao tanque, não ao peixe. A unidade experimental, e portanto a réplica, é o tanque.

Vale simular os quatro experimentos para compreender o que cada um permite aprender sobre as fontes de variação nele envolvidas. Como nenhum planejamento acontece sem uma expectativa a respeito dessas fontes, vamos fixar três magnitudes:

  • Variação entre peixes: peixes de um mesmo tanque diferem entre si com desvio-padrão \(\sigma_P = 0{,}8\) cm;
  • Variação entre tanques: tanques tratados da mesma forma diferem entre si com desvio-padrão \(\sigma_T = 0{,}5\) cm;
  • Variação entre dietas: a dieta enriquecida acrescenta \(\Delta = 1{,}0\) cm ao comprimento médio, sobre uma média de 10 cm na dieta comum (o que o experimento deseja estimar).

A Figura 1 simula um experimento para cada uma das quatro opções. A simulação tem dois passos, que correspondem aos dois níveis do experimento. Primeiro sorteamos a média de cada tanque e depois sorteamos os peixes dentro dele.

Ver a simulação dos quatro desenhos 
set.seed(174)

orcamento <- 120
comprimento_base <- 10
efeito_dieta <- 1.0
sigma_tanque <- 0.5
sigma_peixe <- 0.8

simular_desenho <- function(n_tanques) {
  peixes_por_tanque <- orcamento / n_tanques
  dieta <- rep(c("comum", "enriquecida"), each = n_tanques / 2)

  media_tanque <- rnorm(
    n_tanques,
    mean = comprimento_base + efeito_dieta * (dieta == "enriquecida"),
    sd = sigma_tanque
  )

  tibble(
    desenho = paste0(n_tanques, " tanques de ", peixes_por_tanque, " peixes"),
    tanque = factor(rep(seq_len(n_tanques), each = peixes_por_tanque)),
    dieta = rep(dieta, each = peixes_por_tanque),
    comprimento = rnorm(orcamento,
                        mean = rep(media_tanque, each = peixes_por_tanque),
                        sd = sigma_peixe)
  )
}

desenhos <- c(2, 4, 8, 20)
experimentos <- lapply(desenhos, simular_desenho)
limites_y <- range(bind_rows(experimentos)$comprimento)

painel_desenho <- function(dados) {
  media_tanque <- dados |>
    group_by(tanque, dieta) |>
    summarise(media = mean(comprimento), .groups = "drop")

  media_dieta <- dados |>
    group_by(dieta) |>
    summarise(media = mean(comprimento), .groups = "drop")

  ggplot(dados, aes(x = tanque, y = comprimento, colour = dieta)) +
    geom_hline(data = media_dieta, aes(yintercept = media, colour = dieta),
               linetype = "dashed", linewidth = 0.4) +
    geom_jitter(width = 0.15, alpha = 0.35, size = 1) +
    geom_point(data = media_tanque, aes(y = media), shape = 95, size = 7) +
    coord_cartesian(ylim = limites_y) +
    scale_x_discrete(guide = guide_axis(check.overlap = TRUE)) +
    scale_colour_manual(values = c(comum = "#0072B2", enriquecida = "#D55E00")) +
    labs(title = unique(dados$desenho), x = "Tanque", y = "Comprimento (cm)",
         colour = "Dieta") +
    theme_bw(base_size = 11) +
    theme(axis.text.x = element_text(size = 7))
}

patchwork::wrap_plots(lapply(experimentos, painel_desenho),
                      ncol = 2, guides = "collect")

Os quatro painéis nasceram do mesmo processo, com o mesmo efeito real de 1,0 cm, e é com esse valor que cada estimativa deve ser comparada. No desenho de 2 tanques, a diferença entre as linhas tracejadas foi de 0,22 cm, e ela carrega tudo o que separa aqueles dois tanques, porque comparar as duas dietas é literalmente comparar dois tanques. No desenho de 4 tanques, cada dieta já é a média de dois tanques, e a estimativa foi de 0,93 cm. Nos desenhos de 8 e de 20 tanques, em que cada média de dieta se apoia em quatro e em dez sorteios independentes, as estimativas foram de 0,93 cm e 1,30 cm.

DicaObserve

Note que nenhum peixe foi acrescentado entre o primeiro painel e o último. O que mudou foi quantas vezes a dieta foi sorteada de forma independente.

Repare também que nenhum desenho está errado por construção. Distribuir mal os peixes não faz o experimento errar sempre para o mesmo lado, mas torna cada resultado muito mais instável e, por isso, muito mais fácil de confundir com um efeito real.

2.1 Três comparações, três precisões

A Figura 1 ilustra uma única simulação deste experimento, portanto os valores acima valem apenas para esse sorteio. Você pode, e deve, repetir o código removendo a chamada a set.seed() para ver a variedade de padrões que cada um desses experimentos é capaz de gerar.

Para comparar os desenhos sem depender de um sorteio particular, a incerteza de cada comparação pode ser calculada diretamente das três magnitudes já fixadas.

Com \(k\) tanques e \(m\) peixes em cada um, a média de um tanque carrega as duas fontes de variação, do tanque (\(\sigma_T\)) e dos peixes (\(\sigma_P\)), e tem variância

\[ \sigma^2_{\bar y_{tanque}}=\sigma_T^2+\frac{\sigma_P^2}{m}. \]

Falta uma regra, que usaremos três vezes. Quando duas quantidades são independentes, a variância da diferença entre elas é a soma das duas variâncias, isto é, \(\sigma^2_{a-b}=\sigma^2_a+\sigma^2_b\). Se as duas tiverem a mesma variância, o erro padrão da diferença é o erro padrão de uma delas multiplicado por \(\sqrt{2}\).

Com essa regra, podemos escrever o erro padrão das três comparações que o experimento permite, do nível mais baixo para o mais alto.

Dois peixes do mesmo tanque. Os dois compartilham a média daquele tanque, e o que os separa é apenas a variação individual, portanto

\[ \sigma_{y_1-y_2}=\sqrt{2}\,\sigma_P. \]

Nem \(k\) nem \(m\) aparecem aqui, e é por isso que essa comparação tem o mesmo valor nos quatro desenhos.

Dois tanques da mesma dieta. Cada tanque entra pela sua média, cuja variância é a da primeira fórmula desta seção, de modo que

\[ \sigma_{\bar y_{t_1}-\bar y_{t_2}}=\sqrt{2\left(\sigma_T^2+\frac{\sigma_P^2}{m}\right)}. \]

Agora \(m\) aparece, mas dentro da parcela menor, e por isso essa comparação piora só um pouco quando os tanques ficam menores.

As duas dietas. Cada dieta é a média de \(k/2\) tanques, e a variância dessa média é a variância de uma média de tanque dividida por \(k/2\). Aplicando a regra da diferença e substituindo \(m=120/k\), chegamos a

\[ \sigma_{\bar y_1-\bar y_2}=2\sqrt{\frac{\sigma_T^2}{k}+\frac{\sigma_P^2}{120}}. \]

O 120 que sobrou no denominador é o total de peixes. Como \(k\times m=120\), o número de peixes por tanque desapareceu dessa parcela, que é a mesma nos quatro desenhos. Só a parcela dos tanques (\(\sigma_T^2/k\)) responde ao número de tanques.

Repare ainda que, com \(k=2\), esta última expressão e a anterior dão o mesmo valor, porque, com apenas dois tanques, comparar as duas dietas é o mesmo que comparar dois tanques. A Figura 2 reúne as três comparações para os quatro delineamentos.

O painel A da Figura 2 apresenta o erro padrão da diferença entre dois peixes, entre dois tanques e entre as duas dietas. O erro padrão da diferença entre dois peixes do mesmo tanque depende apenas de \(\sigma_P\) e por isso vale 1,13 cm nos quatro desenhos. A comparação entre dois tanques da mesma dieta sobe de 0,72 para 0,84 cm, porque tanques com menos peixes têm suas médias estimadas com menor precisão. Isso não é um problema aqui, já que o objetivo do experimento é estimar a diferença entre as dietas. É justamente esse último erro padrão que cai à medida que usamos mais tanques, de 0,72 cm com 2 tanques para 0,27 cm com 20 tanques. Lembre-se de que um experimento é tanto mais preciso quanto menor for o erro padrão da comparação que interessa, de modo que aumentar o número de tanques aumenta a capacidade de detectar o efeito de 1,0 cm no comprimento médio.

Vale notar onde as curvas se encontram. Com 2 tanques, a diferença entre dietas tem exatamente o mesmo erro padrão que a diferença entre dois tanques quaisquer, porque as duas comparações são a mesma coisa. Nessa situação, os efeitos do tanque e da dieta estão confundidos, o experimento não tem como separá-los e a pergunta inicial não pode ser respondida.

O painel B da Figura 2 decompõe a variância da diferença entre dietas na contribuição dos peixes e na contribuição dos tanques. A parcela que vem dos peixes vale 0,021 cm² nos quatro desenhos, porque todos usam os mesmos 120 peixes. A parcela que vem dos tanques, por outro lado, cai pela metade cada vez que o número de tanques dobra. Com poucos tanques, portanto, o experimento é tanto mais prejudicado quanto mais heterogêneos eles forem, ao passo que essa heterogeneidade, mesmo existindo, pesa cada vez menos quando há muitos tanques (réplicas) por dieta.

A contribuição das subamostras, isto é, de medir mais de um peixe por tanque, é pequena, mas subamostrar não é um problema em si. Medir vários peixes produz uma média mais confiável daquele tanque, e isso melhora a estimativa. O ganho, porém, satura rápido. A parcela \(\sigma_P^2/m\) vale 0,107 cm² com 6 peixes por tanque e 0,011 cm² com 60, sempre pequena diante dos 0,25 cm² que a variação entre tanques acrescenta. Nenhum peixe a mais reduz a variação entre tanques, enquanto cada tanque novo acrescenta uma repetição independente do tratamento e torna o experimento mais capaz de detectar diferenças entre as dietas.

Em resumo, a replicação tem duas funções. Primeiro, permite estimar a variação entre unidades tratadas da mesma forma. Segundo, faz com que uma ocorrência inesperada, como a falha de uma bomba, não determine sozinha o efeito estimado. Para isso, no entanto, as réplicas precisam ser genuinamente independentes e cobrir a variabilidade sobre a qual se pretende concluir.

AvisoUm extremo também não serve

Levar a lógica ao limite e montar 60 tanques de 2 peixes traz outros problemas, como densidades irrealistas, mais trabalho de manutenção e mais chance de perder unidades inteiras durante o experimento.

A decisão, portanto, está em encontrar o ponto de equilíbrio, e ela depende prioritariamente do número de unidades experimentais (tanques), não do número de observações (peixes).

2.2 Quantas unidades em cada tratamento?

Definido o número total de unidades, resta distribuí-las entre os tratamentos. Um desenho balanceado atribui o mesmo número de unidades a cada tratamento. O balanceamento não é exigido por todo modelo, mas torna as comparações mais precisas e menos sensíveis a diferenças de variância. Também evita que a perda de poucas unidades deixe um dos tratamentos quase sem replicação, situação em que o experimento inteiro passa a depender de um punhado de réplicas.

3 Segunda decisão: quem recebe qual tratamento?

Definidos os tanques, resta atribuir as dietas, e essa atribuição precisa ser sorteada.

Sortear impede que diferenças pré-existentes se alinhem com o tratamento. Se a pesquisadora escolher “os tanques mais claros para a dieta nova”, luz e dieta ficam confundidas para sempre, e nenhuma análise posterior será capaz de separar as duas.

O sorteio também cobre o que ninguém pensou em medir, como a posição na sala, a idade da bomba de aeração e a ordem em que os peixes foram capturados. Ele não elimina essas diferenças, mas as espalha entre os tratamentos, em vez de deixá-las acumular de um lado só.

Vale escrever isso com um pouco mais de precisão. Se \(Y_i(0)\) representa o resultado que o tanque \(i\) teria sob a dieta comum e \(Y_i(1)\) o resultado sob a dieta enriquecida, o efeito individual seria \(Y_i(1)-Y_i(0)\). Nunca observamos os dois resultados no mesmo tanque, porque cada tanque recebe uma única dieta. A alocação aleatória contorna esse impasse ao criar grupos comparáveis, de modo que o efeito médio pode ser estimado por

\[ \widehat\Delta=\bar Y_{enriquecida}-\bar Y_{comum}. \]

O símbolo \(\widehat\Delta\) representa a diferença observada entre as médias dos dois grupos. Sob sorteio correto e na ausência de interferência entre as unidades, essa diferença estima sem viés o efeito médio do tratamento. A aleatorização não garante que toda característica fique exatamente balanceada em um sorteio particular, mas garante que os desequilíbrios não sejam produzidos sistematicamente pelo pesquisador, e fornece a base probabilística da comparação.

Na prática, o sorteio balanceado é uma linha de código, e convém que ela seja registrada:

AvisoAleatorizar não é escolher sem critério

“Distribuir de qualquer jeito” e “sortear” não são a mesma coisa. Uma escolha informal tende a seguir padrões que quem escolhe nem percebe.

O sorteio precisa ser feito com um mecanismo explícito, e vale registrar no caderno de campo qual foi.

3.1 Confundimento visto como falta de comparação

O que exatamente se perde quando o sorteio não acontece? A resposta fica clara ao olhar a tabela do desenho. Suponha que todos os tanques da dieta comum fiquem na prateleira superior e todos os da dieta enriquecida, na inferior:

Prateleira Dieta comum Dieta enriquecida
Superior 10 0
Inferior 0 10

Nenhuma comparação nesse desenho separa dieta de posição. Qualquer diferença observada pode ser atribuída igualmente à dieta, à prateleira ou à combinação das duas. Não se trata de um problema de tamanho amostral, pois vinte, duzentos ou dois mil tanques com esse mesmo padrão continuariam confundidos.

No painel de baixo da Figura 3, cada prateleira contém as duas dietas, e por isso a comparação entre dietas pode ser feita dentro de cada prateleira. Foi essa possibilidade que o desenho confundido eliminou.

3.2 Quando o sorteio precisa respeitar a estrutura

O painel inferior da Figura 3 sugere um refinamento do sorteio. A aleatorização irrestrita pode, por acaso, concentrar um tratamento em uma região da sala ou em um lote de peixes. Se uma fonte importante de variação é conhecida antes do experimento, podemos formar grupos homogêneos e sortear dentro deles. Por exemplo, em cada prateleira da sala, metade dos tanques recebe uma dieta e metade recebe a outra. Essa aleatorização restrita preserva o sorteio e impede que a posição se alinhe com o tratamento.

Uma implementação completa cria os grupos primeiro e sorteia os rótulos separadamente em cada um:

Ver a aleatorização restrita por blocos 
unidades <- crossing(
  prateleira = paste("prateleira", 1:4),
  posicao = 1:6
)

plano <- unidades |>
  group_by(prateleira) |>
  mutate(tratamento = sample(rep(c("controle", "dieta nova"), each = 3))) |>
  ungroup()

Esses grupos são chamados de blocos. O bloqueamento não transforma a posição em um tratamento de interesse, apenas retira uma fonte previsível da variação residual. Os blocos precisam ser definidos antes de observar a resposta, e cada bloco deve permitir a comparação entre todos os tratamentos.

3.3 Sortear unidades e sortear tratamentos

Duas operações levam o nome de sorteio e respondem a perguntas diferentes. A amostragem aleatória seleciona unidades de uma população e sustenta a generalização para essa população. A alocação aleatória distribui tratamentos entre unidades já selecionadas e sustenta a comparação causal entre tratamentos. Um estudo pode ter uma sem a outra.

Peixes comprados de um único viveiro podem receber as dietas por sorteio. A comparação causal dentro desse conjunto é forte, mas generalizar o resultado para todas as populações de robalo exige cautela. No sentido oposto, uma amostra aleatória de estuários descreve bem a região, e ainda assim comparar estuários poluídos e não poluídos continua sendo um estudo observacional, porque a poluição não foi atribuída pelo pesquisador.

4 Terceira decisão: o que manter constante?

A última decisão é sobre tudo aquilo que não é o tratamento.

Manter constante o que puder ser mantido constante (temperatura, fotoperíodo, densidade inicial, horário de alimentação, origem dos juvenis) é o que se chama de controle local. Cada fonte de variação eliminada dessa forma deixa de compor a variação residual, e a variação residual é a régua com a qual o efeito do tratamento é julgado.

O efeito da dieta não muda com isso. O que muda é a nitidez com que ele aparece.

Parte dessa decisão é definir contra o que o tratamento será comparado. Um grupo controle representa o que aconteceria sem a intervenção de interesse. Para uma dieta, pode ser a formulação convencional, para um contaminante, a concentração zero, e para um procedimento, um manejo simulado que reproduza o manuseio sem o componente ativo. O controle precisa passar pelas mesmas etapas dos demais grupos, pois qualquer diferença de manejo passa a competir com a explicação do tratamento.

O controle local também tem custo quando levado longe demais. Se todos os tanques usam indivíduos de uma única origem, o experimento mede com precisão o efeito naquela origem, mas pode representar mal outras populações. O objetivo não é eliminar toda a variação biológica, e sim controlar as fontes que obscurecem a comparação e replicar sobre as fontes às quais a conclusão pretende se estender.

Uma última providência diz respeito a quem mede. Quando possível, quem registra a resposta não deve saber qual tratamento cada unidade recebeu. Esse mascaramento não altera a biologia, mas reduz a chance de expectativas influenciarem a medição, a exclusão de observações ou o registro de resultados ambíguos.

NotaTrês decisões, três funções

Quantas unidades experimentais: define quantas repetições independentes do tratamento existem.

Aleatorização: impede que diferenças pré-existentes se confundam com o tratamento.

Controle local: reduz a variação residual e torna o efeito mais fácil de detectar.

As três são decisões de delineamento. Nenhuma delas pode ser tomada depois, na análise.

5 Nem tudo pode ser sorteado

Compreender os elementos discutidos acima é fundamental para conduzir um bom delineamento, mas aplicá-los nem sempre é simples. Em muitos estudos, o “tratamento” é uma condição observada, e não atribuída. Quando o estudo compara costões expostos e abrigados, meses de coleta ou estuários poluídos e limpos, essas condições não são alocadas por escolha do pesquisador.

Nesses casos, ainda vale escolher bem as unidades, replicá-las e controlar o que for possível, para evitar que o confundimento com variáveis que não interessam ao estudo invalide a comparação central.

NotaProtocolo mínimo antes da coleta

Defina a população e a unidade experimental. Liste tratamentos e controle. Escolha replicação e subamostragem. Identifique fontes para bloqueio. Gere e registre a sequência aleatória. Padronize manejo e medição. Planeje mascaramento, perdas e exclusões. Declare previamente respostas e comparações principais.

Os 120 peixes do início continuam sendo 120. O que as três decisões determinam é quanta informação sobre a dieta esses mesmos peixes serão capazes de fornecer, e nenhuma delas pode ser revista depois que o experimento começa. É por isso que o delineamento, e não a análise, é a etapa em que um estudo ganha ou perde a capacidade de responder à pergunta que o originou.
