1 Três papéis, uma mesma fórmula

Fator, bloco e covariável entram todos com + ou * na fórmula do modelo, e o R os ajusta pelo mesmo procedimento. O que os separa não está na fórmula. O fator é o que se quer testar, enquanto bloco e covariável são retirados do resíduo para tornar o teste mais sensível.

Esta atividade pede que você reconheça esse papel em situações novas, e que mostre no R o que acontece quando ele é ignorado.

library(tidyverse)
theme_set(theme_bw(base_size = 12))

2 Quatro situações

Cada situação abaixo descreve um estudo. Para cada uma, decida o papel de cada variável mencionada e justifique.

  1. Um experimento testa três rações para camarões em 12 tanques, montados em três salas com temperaturas ligeiramente diferentes. O que é a sala?
  2. Um estudo compara o crescimento de mudas de mangue em dois substratos. A altura inicial de cada muda foi medida antes do plantio. O que é a altura inicial?
  3. Um experimento cruza duas temperaturas e três salinidades para avaliar a sobrevivência de larvas. O que são temperatura e salinidade?
  4. Um levantamento compara a riqueza de peixes entre dois estuários. A profundidade de cada ponto de coleta foi registrada. O que é a profundidade?

3 Uma simulação para a situação 1

A simulação a seguir reproduz a estrutura da situação 1, com três rações testadas em tanques distribuídos por salas com temperaturas diferentes.

experimento <- tibble(
  sala = rep(1:6, each = 3),
  racao = rep(c("A", "B", "C"), times = 6)
) |>
  mutate(
    media_esperada = 20 + 4 * sala,
    resposta = media_esperada + rnorm(18, mean = 0, sd = 1.2)
  )

sem_sala <- aov(resposta ~ racao, data = experimento)
com_sala <- aov(resposta ~ racao + factor(sala), data = experimento)

DicaPara pensar

Nesta simulação racao não tem efeito nenhum (a média não depende de racao). Ainda assim, compare o quadrado médio residual dos dois modelos e verifique se tratar a sala como se ela não existisse muda a régua usada para julgar a ração.

# Uma simulação para a situação 1

A simulação a seguir reproduz a estrutura da situação 1, com três rações testadas em tanques distribuídos por salas com temperaturas diferentes.

```{r}
experimento <- tibble(
  sala = rep(1:6, each = 3),
  racao = rep(c("A", "B", "C"), times = 6)
) |>
  mutate(
    media_esperada = 20 + 4 * sala,
    resposta = media_esperada + rnorm(18, mean = 0, sd = 1.2)
  )

sem_sala <- aov(resposta ~ racao, data = experimento)
com_sala <- aov(resposta ~ racao + factor(sala), data = experimento)

summary(sem_sala)
summary(com_sala)
```

Nesta simulação `racao` não tem efeito nenhum (a média não depende de `racao`). Ainda assim, compare o quadrado médio residual dos dois modelos e verifique se tratar a sala como se ela não existisse muda a régua usada para julgar a ração.
